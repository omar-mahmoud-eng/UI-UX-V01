# 14 — Authoritative sources to consult before implementing
Verified reference entrypoints as of 2026-10-18. Agent must check current docs against its pinned package version (never blindly copy code for a different Medusa release).

- Official Next.js monorepo starter: https://docs.medusajs.com/resources/nextjs-starter
- Fundamentals modules: https://docs.medusajs.com/learn/fundamentals/modules
- Module isolation: https://docs.medusajs.com/learn/fundamentals/modules/isolation
- Module Links: https://docs.medusajs.com/learn/fundamentals/module-links
- Medusa workflows: https://docs.medusajs.com/learn/fundamentals/workflows
- Plugins: https://docs.medusajs.com/learn/fundamentals/plugins
- Plugin creation: https://docs.medusajs.com/learn/fundamentals/plugins/create
- Infrastructure modules: https://docs.medusajs.com/learn/fundamentals/modules/infrastructure-modules
- Module tests: https://docs.medusajs.com/learn/debugging-and-testing/testing-tools/modules-tests
- Full integration tests: https://docs.medusajs.com/learn/debugging-and-testing/testing-tools/integration-tests
- General deployment: https://docs.medusajs.com/learn/deployment/general
- OWASP Application Security Verification Standard: https://owasp.org/www-project-application-security-verification-standard/
- OWASP API Security Top 10: https://owasp.org/API-Security/
- OWASP Cheat Sheet Series: https://cheatsheetseries.owasp.org/
- Node.js releases and supported runtime: https://nodejs.org/en/about/previous-releases
- PostgreSQL documentation: https://www.postgresql.org/docs/
- Next.js documentation: https://nextjs.org/docs
