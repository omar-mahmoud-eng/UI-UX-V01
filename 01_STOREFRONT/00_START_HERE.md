# START HERE — Google Stitch / Storefront

## Goal
Generate a complete high-fidelity shopper experience (desktop + mobile) for a Saudi artisanal wood + flowers gift e-commerce store. Copy `DESIGN.md` into your Stitch project first (or import as style reference). **There is no final brand name, actual inventory or logo provided; placeholder “وَرْد وَخَشَب” is only a visual concept.**

## Order of operation
1. Open Google Stitch at https://stitch.withgoogle.com/ and create project `Wood & Flowers — Storefront`.
2. Use `00_MASTER_STITCH_PROMPT.md` to establish foundation, styles and shared page shells.
3. Design the screens listed in `01_NAVIGATION_AND_SCREEN_MAP.md` in the priority groups from `03_STITCH_BATCHES.md`.
4. Individual full prompt files are in `SCREEN_PROMPTS/`; grouped prompts by journey in `SECTION_PROMPTS/`.
5. Link screens and validate the scenarios in `02_USER_JOURNEYS.md`, then generate desktop AND mobile variants where specified.
6. Export screens/design to your implementation pipeline; this pack is UX/UI prompts, not functioning storefront code.

## Core value proposition
Bespoke wood engraving + fresh florals + curated gift boxes, scheduled Saudi delivery, elegant gift message and recipient privacy, corporate bulk orders. Never treat a mock screen as inventory availability, shipping estimate or payment integration.
