# Shopper journeys and prototype connections

1. **Engraved wood gift**: Home → Wood collection → Wood PDP → Choose piece/material → Add engraving → Upload art optional → Proof approval → Gift note → Delivery eligibility/date/slot → Payment → Success → Tracking.
2. **Bouquet**: Occasion/flowers → Bouquet PDP → Stem mix/size → Wrapping → Review + substitution consent → Recipient → Date slot → Checkout → Tracking.
3. **Mixed gift box**: Home → Combo collection → Box builder → Add-ons → Arrangement preview → Card + packaging → Split recipients if needed → Checkout.
4. **B2B gifting**: Corporate home → Catalog → RFQ with quantities and brand logo → RFQ confirmation → Buyer portal → Approval → Purchase order.
5. **Service failure recovery**: Out-of-zone address → Pickup or alternative delivery; card declined → retry without duplicate order; sold-out flowers → deliberate substitute approval.
6. **After purchase**: Order detail → status tracking → change slot if policy eligible → support ticket/return and care guides.

Always prototype primary and recovery paths. Do not expose recipient phone/address to the wrong account or show private sender identity when anonymous is selected.
