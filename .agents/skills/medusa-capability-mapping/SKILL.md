# Medusa capability mapping
## When to invoke
Every new feature proposal and dependency request.
## Required context
Read AGENTS.md, docs/11-AGENT-OPERATING-SYSTEM.md, docs/14-OFFICIAL-REFERENCES.md, the active tasks/Fxx file and relevant pinned official reference. Check that current stage is allowed.
## Execution protocol
Map domain need -> pinned Medusa Commerce/Infrastructure Module -> official workflow/API/Admin equivalent -> actual missing capability. Record build vs reuse decision and citation. Surface version mismatches.
## Prohibited
Rebuilding order/cart/price/customer ownership; guessing APIs from old v1 tutorials.
## Evidence
Medusa native capability table, exact version and official URLs, gap approval.
