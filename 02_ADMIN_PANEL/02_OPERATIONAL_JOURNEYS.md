# Cross-domain enterprise workflows to prototype

1. **Wood+flowers bespoke order**: Admin order → verify payment/availability → artwork proof → approve engraving → workshop dispatch → QC photo → floristry pairing → box assembly → pack label → delivery route → ePOD → invoice/ledger review.
2. **Peak floral demand**: forecast → supplier PO → ASN → goods receiving → batch/lot FEFO → bouquet recipe → allocate available stems → controlled substitution approval → last-mile slot capacity.
3. **Corporate gifting RFQ**: customer 360 → B2B RFQ → CPQ margin guardrails → customer quote negotiation → internal approval → purchase order → imported recipient list → production batches → account settlement.
4. **Return and refund**: CX ticket → RMA eligibility personalized/perishable → evidence → supervisor approval → recoverable stock or discard → refund and reconciliation → compliance event.
5. **ZATCA UI review**: invoice creation → XML validation → review report/clearance route → certificate lifecycle state → retry queue → archival and audit. Do not show fake successful compliance.
6. **Marketplace partner and finance**: onboarding KYB → listing/offer → seller SLA → order split → commission → authorized payout and legal controls.
7. **Failure and security**: payment callback duplicate → idempotency inspection → DLQ → operational replay with authorization → audit trail; no manual override without traceability.
