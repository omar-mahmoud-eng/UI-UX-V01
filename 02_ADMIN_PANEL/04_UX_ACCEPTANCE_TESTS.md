# Enterprise UX QA checklist

- [ ] 23 original modules represented, 150 original submodule names, and 2 clearly marked business extensions.
- [ ] Module overview → submodule index → record → config/rules navigates at least three levels.
- [ ] Financial/tax/PII modifications require role-specific confirmation, reason and audit state.
- [ ] Admin shows realistic wood/bouquet production queues, artwork signoff and seasonal inventory FEFO.
- [ ] SAR, RTL Arabic, English LTR, Asia/Riyadh, Arabic/English item names usable.
- [ ] Large grids support keyboard navigation, saved filters and empty/error variants.
- [ ] Order payment, warehouse fulfillment and financial ledger remain separate sources of truth.
- [ ] Demo labels do not assert Medusa ships WMS/TMS/ERP/Marketplace/IFRS/ZATCA certification natively.
- [ ] No direct database edit screens for production orders or double-ledger posting.
- [ ] Mobile tactical screens for picker, courier, florist and POS prepared where useful.
